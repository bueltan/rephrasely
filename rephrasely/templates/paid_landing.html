Why install Rephrasely?

Slack-native workflow

No context switching. The suggestion appears in a Slack modal where users can edit before sending.

No stored message content

Message text is processed in memory for suggestion generation and is not retained by Rephrasely.

Questions before installing

Does Rephrasely replace human review?

No. Rephrasely provides an editable suggestion. Users should review important messages before sending.

Can Rephrasely send messages as the user?

Yes, when the user approves the required Slack user scope during installation.

Is Rephrasely free to inspect?

Yes. The project is open source under the MIT License.
