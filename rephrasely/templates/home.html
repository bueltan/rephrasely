How it works

1. Write a draft

Type /rephrasely followed by the message you want to improve.

2. Review the suggestion

Rephrasely opens an editable Slack modal with an AI-generated improvement.

3. Send as yourself

Edit the final text if needed, then post it with your authorized Slack user token.

Rephrasely FAQ

What is Rephrasely?

Rephrasely is an open-source Slack app that uses AI to suggest clearer wording for messages.

Who is Rephrasely for?

Rephrasely is useful for teams that want clearer Slack messages, better English drafts, and faster message editing.

Does Rephrasely store message content?

No. Message content is processed in memory to generate a suggestion and is not stored.

How do I use Rephrasely?

Type /rephrasely followed by your message in Slack, review the suggestion, and send it.

Can I self-host Rephrasely?

Yes. Rephrasely is open source and can be deployed with Flask, Gunicorn, and your own Slack app credentials.
